# Start here

This sample project has a short script, "Sample script - Ghost towns.md". Three things to try:

1. **Make a voiceover.** Hover the script in Files and press the microphone - or just type
   "Voice the sample script with my voice" in the chat. You'll get an mp3, a wav and subtitles.
2. **Let the agent edit.** Type "Make the first paragraph of the sample script punchier" - it edits
   the file in this project without asking. Commands and anything outside the project ask first.
3. **Look around.** Usage shows each account's limits, Backups keeps a copy every day, and the
   ? button opens the guide.

You can delete this project any time (the bin next to its name) - it moves to the trash folder.
