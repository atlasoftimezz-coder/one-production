      Guide
      How One Production works, in five minutes.
      
      
    
      
    
      
      
      Start in three steps
      
      
      1. Connect an account (Accounts): an Anthropic API key, a Claude login or a Codex login. Each keeps its own email.
        2. 
        
      2. Make a project for each video and drop your script and files into it — or press Try the sample on the start page.
        3. 
        
      3. Talk to it: "tighten the intro", "voice this script with my voice at 165 words per minute".
      
      
      What the assistant can do by itself
      
      
      With a Claude or Codex login (or an API key plus Claude Code) the chat works like Claude Code: it reads and edits the files
         inside the project on its own. Anything else — running a command, touching files elsewhere, the internet,
         using the graphics card — shows a yellow card first: Allow once, Allow this session or Deny. The ✕ button stops it.
      
      
      Model and effort
      
      
      Below the message box, next to the account: which model answers (Opus, Sonnet, Haiku, Fable — or Codex's own list)
         and its effort, how hard it thinks. Higher effort is better on hard work but slower and uses more of the limit;
         auto lets the service decide.
      
      
      Team mode
      
      
      The people button turns the chat into a team: a master (Opus) splits your goal into parts — or you write the parts yourself with
         Parts… — and workers (Sonnet) do them at the same time (3 by default; you set the number in the team settings,
         and each extra worker uses your limits faster), and the master checks each part and writes a final review. Two workers never write
         the same file. If a worker's account hits its limit it saves a handoff and carries on with another account; if none is
         left the team pauses — press Resume when one is free. A part that still isn't right after two reviews comes back to
         you. Spend caps per account (Usage page) pause the team before it spends more than you allow.
      
      
      Script Studio
      
      
      The page button below the message box writes a script from your competitors' style: paste their links (any format, or
         pick a list file), and it reads their YouTube captions, writes a style guide, writes the script with your
         FacelessOS system and has Opus score it on nine points. It rewrites until every score reaches 8 — or keeps the
         best version after 5 rounds and lets you decide. Every version stays in scripts/. FacelessOS comes built in; to use a
         newer version, set its folder under Settings in that window.
      
      
      Voiceovers
      
      
      The microphone next to a script (or just asking in the chat) clones your reference voice, reads every section back to check
         nothing was misread, masters to −14 LUFS and adds an mp3, a wav and subtitles to the project.
         Find best settings (System → Set up / modules → Your voice) tunes the clone to sound as close as possible to your clip.
      
      
      Only clone your own voice, or a voice you have permission to use.
      
      
      Accounts, usage and switching
      
      
      Usage shows each account's 5-hour and weekly limits. At 85% or at a limit, One Production writes a handoff file with the
         whole conversation and offers to carry on with another account, which picks up where the first stopped.
      
      
      Your work is safe
      
      
      • Backups run once a day by themselves; restore any project in one click. Restoring never overwrites — the current version goes to the trash folder.
        • 
        
      • Deleting a project moves it to the trash folder; nothing is erased.
        • 
        
      • Everything runs on this PC. Keys stay in Windows' Credential Manager and are scrubbed from logs, handoffs, exports and backups.
      
      
      Updates
      
      
      System → Updates checks for a new version, downloads it and restarts into it. The previous version stays on disk —
         Roll back returns to it in one click. Updates never touch your projects or settings.
      
      
      When something goes wrong
      
      
      • An account turns red — Accounts → Re-login.
        • 
        
      • "Hit its usage limit" — pick another account, or wait for the time shown.
        • 
        
      • Voice module not ready — System → Set up / modules installs or repairs it.
        • 
        
      • Anything else — System → Export diagnostics and send the zip to whoever gave you One Production.
            It holds the PC scan, versions and error messages — never your chats, files or keys.
