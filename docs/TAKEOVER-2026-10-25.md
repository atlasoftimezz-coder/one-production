## What the application does

One Production is a local Windows application for making YouTube videos. FastAPI serves a vanilla JavaScript browser UI on loopback only. It is a working implementation with substantial tests, rather than an initial scaffold.

| Area | Existing implementation | Main files |
|---|---|---|
| Projects and chat | Streaming chat, uploads, history, isolated provider profiles | `app/main.py`, `app/storage.py`, `app/providers/`, `web/index.html` |
| AI agents | Claude Agent SDK and Codex app-server, tool permissions, approval cards | `app/agent/claude_agent.py`, `app/agent/codex_agent.py`, `app/agent/policy.py` |
| Accounts and usage | Claude/Codex logins, Anthropic API keys, usage ledger, handoff files | `app/accounts.py`, `app/usage.py`, `app/handoff.py` |
| Team and scripts | Master/worker orchestration, competitor captions, script writing/review loops, bundled FacelessOS prompts | `app/agent/team.py`, `app/agent/scriptflow.py`, `app/competitors.py`, `facelessos/` |
| Voiceover | Local Chatterbox cloning, read checks, mastering, subtitles | `voice/`, `app/voice.py`, `app/media.py`, `app/gates.py` |
| Video production | Script → voice → Fusion visuals → render → upload bundle; draft mode can render automatically | `app/agent/episode.py`, `app/fusion.py`, `app/fusion_kit.py`, `app/resolve_runner.py` |
| Visual references and assets | Competitor cut/frame/audio analysis, style profiles, FLUX scene/object generation, Pexels stock, Epidemic SFX | `app/style_probe.py`, `app/styles.py`, `imagegen/`, `app/assets.py`, `app/stock.py`, `app/sfx.py` |
| Knowledge and memory | Local SQLite FTS5 document retrieval, page citations, scoped guidance, retention-based lesson suggestions | `app/knowledge.py`, `app/learning.py`, `app/insights.py` |
| Storage and MCP | Custom stdio/HTTP/SSE servers; local folder and Google Drive import/export | `app/mcp_servers.py`, `app/cloud_storage.py`, `web/mcp.js`, `web/storage.js` |
| Installation and support | Setup wizard, modules, backups/restore, PIN/Google sign-in, portable packages, updates/rollback, diagnostics | `app/installer.py`, `app/backups.py`, `app/update.py`, `tools/build_package.py` |
| Development tools | Phase gate runner and optional model-dispatch/worktree tooling | `tools/check.py`, `dev/dispatch.py` |

The app has roughly 17,000 backend lines and 4,200 browser UI lines. Tests are organized by phases P0–P12. Many integration checks use stand-ins for AI, Resolve, Google and media services; passing those does not establish production output quality.
